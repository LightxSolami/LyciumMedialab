Configuration & accès éditeur

Connectez le projet Supabase de votre magazine. Seule la clé publique « anon » / « publishable » est utilisée ici. Ne collez jamais une clé service_role dans une page web.

  1. Créez un projet Supabase et exécutez le fichier supabase-setup.sql dans le SQL Editor.
  2. Ce site est préconfiguré avec l’URL et la clé publishable/anon de son projet. Pour utiliser un autre projet, copiez ses valeurs ici puis enregistrez-les.
  3. Créez les comptes éditeurs, attribuez-leur le rôle editor dans app_metadata côté serveur, puis faites-les reconnecter. L’accès éditeur ne peut pas être auto-attribué par cette page.
  4. Déployez cette page en HTTPS et autorisez son domaine dans les URL de redirection Supabase pour l’accès par lien e-mail.
